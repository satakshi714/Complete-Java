  • Universal Selector: Selects all elements using *.

3. Combinator Selectors

Definition

Combinator selectors define relationships between elements.

  • Descendant Selector (A B): Selects all B inside A
  • Child Selector (A > B): Selects direct children B of A
  • Adjacent Sibling Selector (A + B): Selects the immediate next sibling B after A
  • General Sibling Selector (A ~ B): Selects all siblings B after A

4. Pseudo Classes

Definition

Pseudo classes style an element in a special state.

  • :link → unvisited link
  • :visited → visited link
  • :active → when clicked
  • :hover → when mouse is over element
  • :focus → when input is selected/focused

5. Pseudo Elements

Definition

Pseudo elements style specific parts of an element.

  • ::selection → styles selected text

7. Color Values

Definition

CSS supports different ways to define colors.

  • Named Color: red, blue, green
  • RGB: rgb(255, 0, 0)
  • RGBA: rgba(255, 0, 0, 0.5)
  • HEX: #ff0000
  • HSL: hsl(0, 100%, 50%)
  • HSLA: hsla(240, 100%, 50%, 0.5)

8. Units in CSS

Definition

Units define the size of elements, text, spacing, width, and height.

Absolute Units

  • cm → centimeter
  • mm → millimeter
  • px → pixel

Relative Units

  • vw → viewport width
  • vh → viewport height
  • % → percentage
  • em → relative to parent font size
  • rem → relative to root font size

9. Original Selectors from Your Code

From your CSS:

  • .box > li → select direct li children of .box
  • .box li ul li → select nested list items inside .box
  • .box ~ #id → select the element with id id that comes after .box as a sibling
  • .box > #p → select direct child with id p inside .box
  • .i > li → direct child list items of class i
  • .bb > li → direct child list items of class bb
  • #container → selects element with id container
